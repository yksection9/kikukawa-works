# デザインの設計メモ(2026-10-24)

共通指針は PC の `caude code/DESIGN.md`。ここはこのサイト固有の決定。

## 題材
- 誰が: 菊川雄士(個人のつくり手)。Claude Code で作ったアプリ・ツール・書籍を売る。
- 誰に: SNS・note・Pinterest から来た人。目当ての作品を見て、開くか買う。
- 用途: 作品を見る → 作品のページで「開く/購入する」。作品数はまだ少ない(1点〜数点)。

## 3案(1案目が推し・採用)

### A 展示室(採用)
サイトは「作品を掛ける壁」。サイト自体は色を持たず、色は作品が持ち込む。
- 色: 漆喰の壁 `#E2E3DE` / 額の白 `#FAFAF7` / 墨 `#1D2127` / 鉛(補足文) `#575C63` / 罫 `#C6C8C1` / 作品の色(作品ごと。ウイスキーは琥珀 `#8E5414`)
- フォント: Zen Kaku Gothic New だけ(400/700/900)。製品ラベルのような硬さがあり、900 が使えるので見出しと本文の差を大きく取れる。
- レイアウト: トップは「額装した1点+美術館のキャプション」。下に作品目録(行の一覧。カードにしない)。
  ```
  | Kikukawa Works                     作品 つくり手 |
  | 見出し(900, 52px)          ┌──────────┐ |
  | 説明文                        │ 額装した作品 │ |
  | [作品を見る]                  └──────────┘ |
  |                               キャプション     |
  | 作品目録 ───────────────────────────── |
  | [小画像] 題名  種類  ひとこと           価格 |
  ```
- 原則: 大胆なのは「壁に掛かった1点」だけ。光は左上の1か所、影は右下へ。
- 定番との違い: 前の版はクリーム+明朝+茶のアクセント+中点の英字ラベル+角丸カード(DESIGN.md §4 の定番そのもの)。それを、灰色の壁・ゴシック1書体・作品ごとの色・行の目録に変えた。

### B 夜の作業机(不採用)
暗い机の上に作品を置く。色: 机 `#1C1E1F` / 紙 `#ECEAE4` / 真鍮 `#B08D57`。フォント: BIZ UDPGothic。作業灯が当たった1点が主役。→ 暗い背景+1色アクセントは §4 の定番②に寄る。

### C 白い製品カタログ(不採用)
白地に大きな作品写真と大きな文字だけ。色: 白 `#FFFFFF` / 墨 `#202326` / 青灰 `#4A5A6A`。フォント: M PLUS 1p。→ 質感がなく「ちゃちい」に寄りやすい(JUDGMENT §6)。

## 値
- 文字: 16 / 20 / 25 / 31 / 39 / 49px(1.25倍)。本文の行間 1.8。
- 余白: 8px の倍数。セクション間 96px、ブロック内 24〜32px。
- 角丸: 額 2px / 小画像 4px / ボタン 10px / 価格の台紙 16px。
- 影: 光源は左上。額の影は墨の色を薄めて右下へ(`rgb(29 33 39 / …)`)。
- 動き: 読み込み時に見出し→額の順で1回だけ浮かび上がる(CSSのみ、reduced-motion で無効)。
