5これまでの数をふり返る

入れた記録そのものを見て、月ごとに比べたり、数が多くなりやすい日の条件を調べたりします。休みの日は数えません。

日ごとの数(月の1日から)
曜日ごとの1日あたりの数

月によって土日の数が違うので、曜日ごとにも比べます。

数が多くなりやすい日・少なくなりやすい日

それぞれの日を、同じ曜日のいつもの数と比べて、その条件の日はほかの日より何%多いか(少ないか)を出しました。

「はっきり」は、日ごとのばらつきを考えても差があると言える条件です(おおよそ95%の確かさ)。日数が5日に足りない条件は「日数が少ない」と出します。

一目で言うと
・練習期間 … 設定を選ぶための練習問題。スライダーを動かして、何度やり直してもOK。
・本番期間 … 設定選びには使わない、最後の本番テスト。ここでも成績が良ければ、本当に使える設定です。
使い方 … ①練習期間の外れ方が小さくなる設定を探す → ②本番期間の外れ方も小さいか確認。練習だけ良くて本番で悪化したら、過去に合わせすぎです。

どちらの期間も、毎日「その日より前の記録だけ」で予想して、実際の数と答え合わせします。違いは使い道です。練習期間は、設定(下のスライダーなど)を選ぶための練習問題です。何度やり直しても構いません。本番期間は、設定選びには一切使わず、最後に成績を見るためだけの本番のテストです。練習でだけ良い点が出る設定(過去に合わせすぎた設定)を見抜くために分けています。予想に使う記録の長さは、この期間ではなく「どれくらい昔の記録から学ぶか」で決まります。

予想のしかた

何日前の数を参考にするか

予想する時点でまだ分からない日は、自動で選べなくなります。

左にすると(1〜2)=過去に細かく合わせる
・良い点: 曜日・セールなどの違いを細かく拾うので、練習期間の外れ方が小さくなりやすい。データが多く、変動の少ないデータに向く。
・悪い点: 偶然のブレまで覚えてしまい、本番期間で成績が悪化することがある(過去に合わせすぎ)。データが少ないと予想が不安定になる。
真ん中(3〜5)=ふつう(初期位置は3)
・細かさと安定のバランスがよい。迷ったらここ。
右にすると(6〜7)=大きなくせだけ覚える
・良い点: 偶然のブレに強く、予想が安定する。データが少ない・日ごとのブレが大きいときに向く。
・悪い点: セールなど特別な日の増え方を小さく見積もる。増える日は予想が低め、少ない日は高めになり、平均に寄った予想になる。
選び方: 練習は良いのに本番で悪化する → 右へ。練習も本番も外れが大きく、予想の上下が小さすぎる → 左へ。
予想に使う情報

念のための検査

予想の計算そのものは毎回同じ手順で動くプログラムなので、普段は押す必要はありません。計算の仕組みを人に説明したいときなどに使えます。

外れ方 = 予想と実際の差の合計 ÷ 実際の数の合計。「いつものやり方」は先週の同じ曜日の数をそのまま使う方法です。
