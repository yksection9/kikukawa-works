Thread Status for Claude 導入ガイド

Claude のプロジェクトとスレッドの状態（作業中・あなた待ち・古さ）を1画面で見る、無料のツールです。

約23秒のデモ動画です（画面はサンプルデータで、実際のスレッド名ではありません）。

ダウンロード（無料）: cc-window-kit.zip
解凍すると cc-window-kit フォルダができます。かんたん版は code/start.bat をダブルクリック（Python が必要。Windows 向け）。

まず、どちらで使うか

かんたん版全部入り版
見えるものこの PC の Claude Code＋ クラウドのプロジェクト／スレッド一覧
準備フォルダを開くだけSupabase 無料登録など（約15分。手作業は3つ）
費用無料無料（Supabase の無料プランで足ります）

まずかんたん版で試し、一覧が欲しくなったら全部入り版へ進むのがおすすめです。

全部入り版の手順 手作業は3つだけ

  1. Supabase の無料アカウントを作る。 supabase.com で Google ログインなどで登録します。
  2. Claude に Supabase コネクタを接続する。 Claude の設定のコネクタから Supabase を選び、ブラウザで承認します。
  3. 解凍した cc-window-kit フォルダを Claude に接続し、下の依頼文を貼る。 残りの作業（プロジェクト作成、鍵の生成、テーブル作成、設定ファイル、動作確認）は Claude が進めます。
  4. できあがった文面を、Claude の「好み（Preferences）」に1回貼る。 各スレッドが返信のたびに自分の状態を記録するようになります。効かないプロジェクトだけ、そのプロジェクトの指示にも貼ってください。
  5. 窓を開き、スレッド一覧に出れば完了です。

Claude に貼る依頼文

Thread Status for Claude のセットアップをお願いします。私への確認なしで、次の順に進めてください。失敗したら原因を1〜2文で教えてください。鍵や秘密は会話に書き出さないでください。
1. 診断: Supabase コネクタと cc-window-kit フォルダが使えるか確認する。使えなければ、足りないものを1行で伝えて止まる。
2. Supabase のプロジェクト一覧を見る。「cc-window」という名前のものがあればそれを使う。無ければ無料プランで新規作成する（料金が0であることを確認。0でなければ止まって私に聞く）。
3. 窓の鍵として、ランダムな40文字の英数字を作る（会話には出さない）。
4. setup/schema.sql の __WINDOW_KEY__ をその鍵に置き換えて、execute_sql で実行する。
5. プロジェクトの URL と公開(anon)の鍵を取得し、cc-window-kit フォルダと同じ階層の claude_state/supabase_read.json に {"url":…, "key":…, "header_key":…} で保存する。
6. setup/user_instruction.md の __SUPABASE_PROJECT_ID__ を実際のIDに置き換えた文面を、setup/my_instruction.md に保存し、画面にも出す。
7. 動作確認: テスト行を1つ書き込み、読み戻せるか確かめる。確認できたらテスト行を削除する。
8. 最後に「できたこと／私が次にやること」を3行以内で報告する。

つまずいたら

Supabase の無料枠は2プロジェクトまで。すでに2つある場合は、使っていない方を一時停止または削除してください（どちらにするかはご自身で選びます）。
Supabase が一時停止していた。長く使わないと無料プランのプロジェクトは一時停止されます。Supabase の画面から再開できます。
好み設定が効かないプロジェクトがある。そのプロジェクトの「プロジェクトの指示」に同じ文面を貼ってください。

安全について

状態はあなた自身の Supabase にだけ保存されます。作者のサーバーは通りません。保存するのは、プロジェクト名・スレッドの題名・状態・次に要ることの短い一言だけで、会話の本文は保存しません。依頼文を実行すると Claude があなたのデータベースに書き込みます。内容は上の手順のとおりなので、読んでから貼ってください。

このツールは Anthropic 社とは関係のない、個人が作った非公式ツールです。Claude の仕様変更で動かなくなることがあります。
